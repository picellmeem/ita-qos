# 🎬 Demo Script — สำหรับ Screen Recording (2-3 นาที)

ทำเป็นวิดีโอสั้นๆ ใส่สไลด์ตอน present ได้ หรือเล่นสด

---

## เครื่องมือบันทึก
- **Windows Game Bar** (Win + G) — บันทึกหน้าจอแบบง่าย
- **OBS Studio** ฟรี (แนะนำ) — บันทึกได้คุณภาพดี + ตัดต่อง่าย
- **Loom** — ออนไลน์ ลิงก์แชร์ได้ทันที

## ขั้นตอนเตรียมก่อนบันทึก
1. ✅ Login บนเครื่องที่จะอัด
2. ✅ ปิดแท็บอื่นๆ ที่ไม่ใช้ (กัน notification)
3. ✅ ตั้ง browser zoom = 100%
4. ✅ เปิด full screen mode (F11)
5. ✅ เตรียม **มือถือ** ไว้สแกน QR ตอน demo

---

## 📋 Storyboard (3 นาที)

### 🎬 Scene 1: Hook + Landing (10 วิ)

**ภาพ:** เปิด `https://ita-qos.vercel.app/` → เห็นหน้า login พื้นหลังสีสวย

**Narration:**
> "นี่คือ ITA-QOS — ระบบติดตามยาและเครื่องมือแพทย์ด้วย NFC"

---

### 🎬 Scene 2: Login (5 วิ)

**ภาพ:** ใส่ email + password → กด "เข้าสู่ระบบ"

**Narration:**
> "เริ่มจากการ login — ระบบรองรับ role-based access"

---

### 🎬 Scene 3: Dashboard ภาพรวม (20 วิ)

**ภาพ:** เห็นหน้า Home → คลิก "Pharmacy Module" → ดู Dashboard

**Narration:**
> "เข้ามาจะเห็นหน้าหลัก เลือกโมดูล Pharmacy
> ดูสรุปสถานะ — ยาทั้งหมดกี่ตัว เขียวกี่ตัว เหลืองกี่ตัว แดงกี่ตัว
> มีกราฟ donut, bar, area แสดงแนวโน้ม
> และตารางทุกรายการที่ค้นหาได้"

---

### 🎬 Scene 4: Item Detail + QR Code (25 วิ)

**ภาพ:** คลิกที่รายการยาที่ "ด่วน/แดง" → เห็น detail page → focus ที่ QR Code

**Narration:**
> "คลิกเข้าไปดูรายละเอียด — ระบบบอกชัดว่าหมดอายุเกินกี่วันแล้ว
> ทุกรายการมี QR code สำหรับ scan
> เราจะลอง scan ด้วยมือถือดู"

---

### 🎬 Scene 5: Mobile NFC/QR Scan (30 วิ)

**ภาพ:** เปลี่ยนเป็น screen recording ของมือถือ
1. เปิดกล้อง scan QR
2. เด้งเข้า browser แสดงหน้ารายการ
3. ดู status banner สีแดง
4. scroll ดูข้อมูลครบ

**Narration:**
> "พยาบาลหรือบุคลากรไม่ต้อง login
> แค่ scan QR หรือ tap NFC tag
> ระบบจะแสดงข้อมูลครบทันทีในหน้ามือถือ
> สถานะสีแดงเตือนว่ายาตัวนี้ห้ามใช้
> ทุกการ scan จะถูกบันทึกใน audit log"

---

### 🎬 Scene 6: Edit + Audit Log (20 วิ)

**ภาพ:** กลับ desktop → คลิก "✏️ แก้ไข" → แก้ next maintenance date → save → ไปหน้า audit log

**Narration:**
> "เภสัชกรหรือทีมซ่อมที่มีสิทธิ์ จะแก้ไขได้
> ทุกการแก้ถูกบันทึก audit log — ตามรอยได้ว่าใครทำอะไรเมื่อไร"

---

### 🎬 Scene 7: Print Stickers (15 วิ)

**ภาพ:** คลิก "พิมพ์ Stickers" → เลือกรายการ 12 ตัว → กดปุ่มพิมพ์ → เห็น preview A4

**Narration:**
> "ระบบพิมพ์ QR sticker เป็น A4 ให้พร้อม
> ตัดแล้วแปะข้างยาหรือเครื่องได้ทันที"

---

### 🎬 Scene 8: Mobile Responsive (15 วิ)

**ภาพ:** ย่อ browser หน้าต่างให้แคบ → เห็น sidebar กลายเป็น drawer + ปุ่ม ☰ → กดเปิด

**Narration:**
> "ระบบรองรับมือถือเต็มรูปแบบ
> Sidebar กลายเป็น drawer
> เภสัชกรสามารถเช็คข้อมูลขณะเดินใน ward ได้เลย"

---

### 🎬 Scene 9: Dashboard Charts + Export (15 วิ)

**ภาพ:** กลับมา dashboard → ชี้ที่กราฟ → คลิก Export → เลือก PDF → preview ขึ้น

**Narration:**
> "ผู้บริหารดู Dashboard เห็นแนวโน้ม
> Export เป็น Excel หรือ PDF ส่งรายงานต่อได้"

---

### 🎬 Scene 10: ปิด (5 วิ)

**ภาพ:** กลับมาหน้า home → freeze frame + ขึ้น URL

**Narration:**
> "ITA-QOS — ลองใช้งานจริงได้ที่ ita-qos.vercel.app"

---
